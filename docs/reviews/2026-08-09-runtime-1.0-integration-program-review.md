## Verified decisions

- ADR-0034のV1 LAB scopeと`HIL_VERIFIED` ceilingを変更せず、完成対象をV2 /
  Runtime 1.0へ分離している。
- ADR-0032どおり、MFDTはRuntime work、route/parentとFRAGは
  `reliability_work`、packet-linkはFabric workが所有する。
- Identity consumer実装前に、identity-precondition contractの`SPEC_ACCEPTED`と
  compatibility authority更新を必須にしている。
- direct Attachment、cold pre-Attachment forwarding、post-Attachment RRMPを混同しない。
- M7 closure、NRW1 LINK/FRAG、U6をM8より前へ置き、MFDTとM1b/M2は独立parallel
  laneとしてM11前に合流する。
- M7の50-node profile、M8の100-node topology soak、M9のsplit-brain HILを縮小しない。
- NJM1 wire、LAB binding、raw secret、固定pair/flow/service前提を正式Runtimeへ昇格しない。

## Rejected during review

1. ADR-0034と矛盾する「Runtime V1」再定義。
2. AttachmentやMFDTを`reliability_work`へ入れるbudget変更。
3. Proposed identity contractを実装authorityとして先行利用すること。
4. 既存PA-S/M/Cとは別のI0〜I8 status taxonomy。
5. MFDTをM8 relayの不要な直列blockerにすること。
