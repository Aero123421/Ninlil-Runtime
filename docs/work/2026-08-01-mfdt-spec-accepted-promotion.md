# MFDT v1 SPEC_ACCEPTED promotion

Date: 2026-08-01  
Status: **SPEC_ACCEPTED design authority — private/default-OFF software candidate; release and HIL pending**

## Decision and evidence

The fresh independent review of ADR-0021's current S1–S5 exact design returned
**P0=0 / P1=0 / P2=0** and the focused specification suite returned **10/10**.
ADR-0021 is therefore promoted to `Accepted / SPEC_ACCEPTED` as design authority.

The promotion makes no wire-value or storage-format change. Accepted control
versions remain `[1, 2]`; `private_control_protocol.proposed_versions` becomes
empty; a separate `private_mfdt_protocol` version `[1]`, bound to base control
`[1, 2]`, is the exact compatibility authority.

## Promotion changes

- ADR status, MF-O01/MF-O02/MF-O06/MF-O07, compatibility matrix, README, and
  current design summaries are synchronized.
- Machine top status is `SPEC_ACCEPTED_DESIGN_AUTHORITY`; MF-O01 is
  `SPEC_ACCEPTED_GREEN`; generator, Python, Node, C, and acceptance hardpins are
  regenerated by the existing authority resync tool.

  `OPERATOR=1`, `SUPERSEDED=2`, `DEADLINE=3`, `POLICY=4`, with no legacy aliases.
- Accepted U5/U6 files are not edited.
